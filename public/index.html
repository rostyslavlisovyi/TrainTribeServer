Welcome to TrainTribe API

About

TrainTribe API - a platform for connecting athletes with a comprehensive system for trainings, reviews, and points.

Our API provides endpoints for:

  • User Management - user account management
  • Training Sessions - creating and managing training sessions
  • Review System - review system with ratings (1-5 stars)
  • Points System - points system for participation and organization
  • Leaderboard - monthly user ranking
  • City Data - city information
  • File Uploads - image uploads

Key Features

  • Create and participate in training sessions
  • Review system only for participants of completed trainings
  • Automatic points allocation (5 for organizing, 1 for participation)
  • Rating system with automatic average score calculation
  • Review status tracking for each participant
  • Monthly leaderboard with user search
  • Full JWT authentication and authorization
